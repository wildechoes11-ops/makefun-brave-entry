**The First Plank** is a short scene about a dog crossing a footbridge. The program writes the same UTF-8 text on every run and needs no dependencies or network access.

## Run it

Use Node.js 22.18 or later. The judge runs `node main.ts` and reads `/output/entry.txt`. To test locally, write to a temporary directory:

```sh
ENTRY_OUTPUT_DIR="$(mktemp -d)" node main.ts
```
